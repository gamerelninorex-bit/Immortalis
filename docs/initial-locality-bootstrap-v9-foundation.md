## Source interpretations and subsequent authority

1. **Producer-input identity (C-1).** The [conformed clarification](https://app.notion.com/p/40d20af901e081309889e8333d2a9286), native pin `2026-11-03T00:51:23.053Z`, defines the non-circular pre-task hash H over the producer object P without `task_id`, `T` over `{campaign_id, setup_id, phase, input, input_hash: H}`, and the delivered bytes D = canonical `{...P, task_id: T}`. The runner refuses unless the bytes to be delivered are byte-equal to D, before the send window opens. The model copies `task_id` only (parser V2). The signed context manifest is recomputed from the immutable instruction-map registry and D; a proved mismatch is a terminal `INVALID_OUTPUT` (`CONTEXT_MANIFEST_MISMATCH`) that retains the signed Response, and an unverifiable source fails closed. The [Sovereign ratification](https://app.notion.com/p/40d20af901e081ea9235df051dbf9908), pin `2026-11-03T00:54:41.601Z`, adopts C-1 and C-2; [BLUE's same-PR instruction](https://github.com/gamerelninorex-bit/Immortalis/pull/95#issuecomment-6646298168) authorizes their implementation here.
2. **Selected-leaf paths (C-2).** The same clarification supplies the closed indexed path/facet/value grammar: twelve unconditional paths, one `actors.constraints[i]` per element, `source_claims[0].claimant` only when non-null, no catch-all. `INITIAL_LOCALITY_PROVENANCE_V1` validates each entry at its own path and value. Verbatim matching is a mechanical floor, not proof that a quotation's meaning, negation or entailment is right; semantic association of a source value with a facet is the signed SCOPE interpretation.
3. **Set-valued arrays.** Pin arrays, evidence quotes and restrictions are held lexically sorted and unique.
4. **`pre_state`.** `head` is `revision:<n>` and `basis_hash` hashes the projection hash and the revision, so a stale Input is refused.
5. **Stable source fields.** The guard reconstructs the pinned source value by reversing its recorded contiguous delivery chain and recomputes the Input projection hash. This directly checks the canonical Input baseline while permitting lawful recoverable/delivered/exhaustion changes. Higher-version stable-field mutation and legitimate drawdown falsifiers are in `tests/conformance/initial-completion-sunset.test.ts`.
6. **Engineering choices inside the adopted text** (none changes a ratified semantic): an empty array is never a candidate fixed actor set; for a fixed facet the legal enum values are filtered by the accepted restrictions and exactly one must remain; a refusal before the send window is not remembered against the task, so the reservation stays retriable.
