# Live host exercise — BLUE v5.1 original active-PC qualified physical-locus custody (what was and was not observed)

> **Repair 1 (BLUE hold on `792a42e97fa18ded001f63c406ac7acf743e2287`).** The first version of the physical question treated _any_ claim about an actor or a right in the player's statement as something the presence rests on, so scenario 4 below (native presence stated, then a guard's oath stated beside it) was refused. That was a defect of this implementation, not a finding of the frozen sources: IR §12 forbids inventing an actor's willingness, not the player's explicit native presence. External claims now carry a `bearing` (`CONTINGENT` / `CONJUNCTIVE`); see [the repair section at the end](#repair-1-contingent-versus-conjunctive-claims). The 17 first-round files below are kept unchanged as the held witness; the repair runs are under `b51-physical-locus-live-host/repair-1/`.

> **This is a finite, single-model, single-session exercise, not an acceptance proof.** It is retained so a person can read exactly what a real AI host was shown and what it answered, and judge the readings for themselves. **No semantic acceptance is claimed from it.** The automated suite proves only plumbing (its hosts are scripted policies the tests wrote).

## Whether a genuine AI-host semantic exercise occurred

**Yes, with the limits below.** The host was a **real headless Claude Code client** (`claude -p`, Claude Code 2.1.296, model `claude-sonnet-5-5` per the client's own init record) registered to the **real `immortalis-referee` stdio MCP server** (`--mcp-config`, `--strict-mcp-config`, tools restricted to the three referee tools) under the existing Claude Code subscription of the build session. No API key, new credential, purchase or network call was used or created by the engine or by this work. The client was given only the generic instruction in `host-prompt.txt` — no answers, no verdicts, no witness text. It discovered and called `referee_list_tasks`, `referee_get_task` and `referee_submit_decision` unaided and wrote its own answers. The engine side was the **shipped `immortalis-operator` binary as real processes** (`establish-locality` → `referee-bind-host` → `author-character` → `establish-character-locus`); the driver (`run-exercise.mts.txt`) only typed the **player's** lines and the confirmation phrases the service had printed, and launched the client whenever a question was pending. Code under test: the implementation commit `3f72a9f7836d4930ddec2049f2ae14933516c468` (the evidence commit adds only files under `docs/evidence/`).

### Honest limits

1. **One model family, one session, finite.** 17 client runs (each answered exactly one question) across seven scenarios. The same session wrote the player's sentences and the worlds with the expected outcomes in mind. A different model, an interactive chat client, a hostile player, longer or non-English text and subtler worlds were **not** tried.
2. **No person has reviewed these readings.** The engine checked that each answer was well-formed, complete and quoted the delivered words verbatim, and derived each verdict itself; it did not and cannot check that a reading was _right_.
3. **Two of the negatives never reached the physical question** (`n4`, `n5`): the earlier native/compatibility question already stopped them (`UNRESOLVED` / `WORLD_CONFLICT`), so a **real-host** physical-stage "elsewhere" or "world excludes a material body" contrast was **not** exercised. Those two contrasts at the physical stage are covered by scripted-host tests only. This is a limitation, not a failure.
4. **Model variance is real and visible.** A first run of the same driver (before a cosmetic console fix; its files were not retained) put `n2` through to the physical stage; in the retained run the I-002 classification of the first `n2` wording was `BLOCKED` (the host treated "stand in different parts of the marsh" as placement the player may not author), so the case stopped at the keep. The reworded `n2b` reached the physical stage. Both are kept.
5. **No adversarial prompt-injection witness was run** against a live host.
6. The host supplied no `claimed_model` label (optional, self-reported); the model above is the client's own init record.

## What this does and does not show

- **Shows:** the end-to-end mechanism works with a real tool-calling host over the real stdio MCP server and real processes for the third operation; that an LLM host given the closed vocabularies produced answers that satisfied the engine's coverage and quotation checks on first try in all retained submissions; and that on these witnesses its readings were, to this author's eye, what a reasonable reader would give, including the one that distinguishes an incorporeal presence from a material one although both state native presence at the locus.
- **Does not show:** reliability across models, runs, languages, adversarial players or subtler worlds; absence of prompt-injection weaknesses; that a person would accept these readings; an ordinary user-facing game host (still absent).
- **Open for a reviewer:** whether the closed form/presence vocabularies need more modes; whether the I-002 treatment of placement words inside a form statement (3a) is the intended law.

18 client runs, 18 `referee_submit_decision` calls, all accepted first time, 0 tool errors. The same limits as above apply (one model family, one author for the witnesses, no human review, no injection witness), and the scenarios that were stopped earlier by the native/compatibility question (the "far hill-town" presence, the world that excludes bodies) were not re-run because the repair does not touch that stage.

**What the repair does not claim.** `bearing` is the host's semantic reading of the player's words; the engine checks that the presence quotation stands apart from a conjunctive claim's words and refuses an answer where it does not, but it cannot check that the host read the bearing _rightly_. A model could call a contingent claim conjunctive; the retained decision, the findings, the player's own confirmation and the custody's lack of any field for an actor, right or world claim bound that risk and do not remove it.
