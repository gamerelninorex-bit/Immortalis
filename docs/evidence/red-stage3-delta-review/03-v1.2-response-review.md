Outside the engine package, `.store` is referenced **251 times in 43 files** (operator 164 in 27, protocol 26 in 7, phone 61 in 9), with **51** adapter constructions in production code. Test code references it **5,840 times in 350 files**. (Coarse pattern; counts include non-campaign `.store` uses.) Making the raw store private is therefore a package API break across production and most of the test harness, and tests need a defined audit-reader replacement.
