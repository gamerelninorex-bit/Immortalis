# B2 modelling choices BLUE should confirm

None of these reopens a settled decision. Each is a place where the construction brief and the ratified sources leave the _shape_ of the
mechanism to the Builder, so the Builder chose and says so. If BLUE disagrees with one, the change is local to the file named.
