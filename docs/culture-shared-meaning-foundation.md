## Lifecycle

1. **Observations (foreign, committed).** Acts / participants / exposure only.
2. **Seal.** `sealUpdateContext(request)` binds the referent and scope, pins the trigger and every source at their current version and group (AS-OF-NOW only — an AS-OF-DECLARED-CLOSE input is CONDITIONAL and stops here), asks Port B for the live Cohort vouch, and commits one outcome-neutral context.
3. **Register.** The dependent consequence's object may register only now — after the seal and **before the decision** (CJA1 §3.3 / §10.B: cause → seal → register → decision → close). Registration admission refuses a Culture-producing declaration once that update's decision exists, so a committed record can never bootstrap a late-registered object; a later consequence that only **reads** the committed meaning declares no Culture stage and stays lawful.
4. **Adjudicate.** The in-process `role.gm + permission.rule.adjudicate` precondition is checked first (merged CJA1); the scripted/GM judgment is journaled once, immutably. No live authentication is claimed.
5. **Close.** The coordinator resolves the Culture stage: context + decision, NOW. Only `ESTABLISH_SUPPORTED` writes the fact. `NOT_SUPPORTED`, `UNRESOLVED`, `DERIVE_WITHOUT_PERSISTENCE` and an absent decision write nothing.
6. **Consume.** The consequence reads the meaning AS-OF-NOW after the close; a later consequence adopts it by identity.

A **later true distinct trigger** yields a distinct update identity over the same slot; it may be judged, but its close can **never overwrite an occupied slot** (occupied-slot evolution is deferred).

## Judgment calls and open findings (none resolves an open gate)

- **Source status.** CJA1 v1.1 is Sovereign-approved only for the two bounded decisions; its limitations (no RED same-version confirmation, no native pin, no spec lock) are not cured here.
- **Declared consequence sources.** PCB-01's `consequence_sources` are consumer-declared. The Culture verifier takes them as explicit host configuration and refuses a declaration that omits any register Population's latest close consumed from. A register Population has never consumed from stays host configuration — a raw archivist commit cannot prove completeness of an undeclared register.
- **`reconciliation: DUE_COMPLETED`** is representable but the live verifier reports `NOT_DUE`: a due reconciliation that has completed is indistinguishable, from committed state, from nothing due.
- **Non-establishing results.** A non-`ESTABLISH_SUPPORTED` decision leaves the Culture stage unresolved (`SOURCE_INVALID`), so dependents wait; no Culture fact and no false negative is written.
- **Manifestation** remains an opaque identifier with no vocabulary; the access class remains engine-side (`culture.engine-sealed`).
- **No real-OS-process cut** was added: no new persistence path exists.
